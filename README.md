# 尋根系統 (FindRoot) - 祖先牌位與族譜管理系統

「尋根系統（FindRoot）」是一套專為華人家族族譜編修、世系傳承與祖先神主牌位整理所設計的現代化管理軟體。系統整合**農曆與國曆雙向即時換算**、**生卒年月日時辰天干地支對照**、**祖先牌位中行「兩生合一老」字數格式規範自動校驗**，並能基於父母親屬關係自動繪製**互動式世系圖（族譜樹）**與產出標準直書神主牌位排版。

---

## 系統特色

1. **典藏級 3D 浮雕祖先牌位與「兩生合一老」天體羅盤 (Awwwards / Webby / FWA 級標準)**：
   - 依據傳統民俗「生、老、病、死、苦」五字天機神數，中行神主字數需合「老」（如 7、12、17、22 字）或合「生」。
   - 頂部雕造祥雲螭龍雕飾牌頭、雷雕堂號匾額、多層須彌仰覆蓮花座與金箔光澤，提供老紅木、沉香黑檀與白底印樣切換。
   - 配備環形動態「五德天體羅盤」（`FiveFateCompass.vue`）與魯班尺文公尺吉數規矩，即時運算旋轉相位與依禮補字建議。
2. **古典雅樂聲學合成引擎 (Web Audio API)**：
   - 零外部音訊檔案依賴，純數學合成宮商角徵羽五音磬鐘與古琴餘韻（523Hz～880Hz）。
   - 頂部導覽列提供雅樂啟閉控制；牌位刻立、族人選取與 AI 答覆皆具備沉浸式磬鈴反饋。
3. **絲綢卷軸世系族譜（族譜樹）互動視覺化**：
   - 古典水墨宣紙絲綢背景、開基水印、竹簡玉牒卡片與世代昭穆印璽。
   - 支援畫布滑鼠平移（Pan）、滾輪縮放（Zoom）、HUD 搜尋先人高亮定位與子孫分支展開收合。
4. **國曆／農曆／干支／時辰雙向即時轉換**：
   - 輸入西元日期自動換算農曆月日、閏月與天干地支生肖。
   - 支援古書族譜常見的農曆與十二時辰（子丑寅卯...）輸入，並自動反推西元日期與民國紀年。
5. **文淵閣 AI 智慧禮制問答助手**：
   - 內建專家知識庫解答神主牌位、干支八字、堂號淵源與開基祖世系歷史。
6. **單一檔案 SQLite 資料庫**：
   - 免配置外部資料庫伺服器，單一檔案（`findroot.sqlite`）即可運作。
   - 支援單鍵下載全庫 JSON 備份檔與本機檔案還原。

## 技術棧

- **前端**：Vue 3 (Composition API)、Vite、Tailwind CSS、Lucide Icons
- **後端**：Node.js、Express (ESM)、SQLite (`better-sqlite3`)
- **曆法核心**：`lunar-javascript`（精確支援西元 1900～2100 年國農曆、干支、生肖與節氣）

## 快速啟動指南

### 環境需求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安裝與啟動

#### 方式一：傳統 Node.js 啟動

1. **安裝所有相依套件**：
   ```bash
   npm run install:all
   ```

2. **建置前端資源**：
   ```bash
   npm run build:frontend
   ```

3. **啟動整合伺服器**：
   ```bash
   npm start
   ```
   啟動後，使用瀏覽器打開：**`http://localhost:3001`**

> **開發模式（前後端獨立熱重載）**：
> - 啟動後端：`npm run dev:backend`（監聽 3001 端口）
> - 啟動前端：`npm run dev:frontend`（監聽 5173 端口，自動代理 API 至 3001）

#### 方式二：Docker 容器化部署 (推薦)

本專案支援多階段 Docker 映像檔構建，自動編譯前端並掛載 SQLite 資料持久化目錄：

1. **使用 Docker Compose 單鍵啟動**：
   ```bash
   docker compose up -d
   ```
   
2. **或手動使用 Docker 指令建置與運行**：
   ```bash
   # 構建映像檔
   docker build -t findroot .

   # 啟動容器 (掛載本地 ./data 目錄以持久化保存 SQLite 資料庫)
   docker run -d -p 3001:3001 -v $(pwd)/data:/app/backend/data --name findroot-app findroot
   ```
   啟動完成後，造訪 **`http://localhost:3001`** 即可使用。

## 操作詳細說明

### 1. 宗族總覽看板 (Dashboard)
- 進入系統後首頁為「宗族總覽」，展示當前宗族堂號（如：穎川堂）、開基祖、世代輩序詩（行輩歌）與宗族源流簡介。
- 右上方數據卡即時顯示宗族總人數、傳承代數、已故先人數與健在裔孫數。
- 可透過快捷按鈕直接跳轉「檢視世系樹」、「牌位工作室」或「登錄新族人」。

### 2. 登錄族人檔案 (Member Management)
點擊頂部導航之 **「登錄族人」** 或於名冊中點擊 **「+ 登錄新族人」**：
1. **名諱與行輩**：
   - 輸入姓氏、名字、性別（男考/女妣）。
   - 輸入世數（第幾代）與行輩字輩（如「廷」、「德」、「承」）。
   - 可選填排行（長男、次女等）、字號與諡號。
2. **雙親與配偶關係**：
   - 下拉選單選擇生身父親與生身母親（系統將依此自動建構世系圖譜）。
   - 可綁定配偶關係。
3. **生卒日期與時辰（國農曆雙向切換選取器）**：
   - **西元國曆模式**：點選日期選擇器，系統即時自動計算出農曆年月日（如：`戊辰年九月十五`）與民國紀年；並可選擇出生或逝世時辰（子丑寅卯...）。
   - **傳統農曆模式**：若參考舊族譜，可直接輸入西元年或干支、農曆月份、日期（可勾選閏月）與時辰，系統將精準反推回國曆西元日期。
4. **仙逝與安葬地**：
   - 若先人已仙逝，勾選「已仙逝」，填寫忌辰與安葬位址穴位座向（如：三峽大埔山麓 坐北朝南）。
5. 點擊 **「確認登錄」** 儲存。

### 3. 家族世系圖譜操作 (Family Tree)
點擊頂部導航 **「族譜世系圖」**：
- **切換始祖**：左上方下拉選單可選取不同的世系起點（如開基一世祖）。
- **畫布拖曳與縮放**：在畫布任意空白處按住滑鼠左鍵即可平移拖曳；右上角提供「+（放大）」、「-（縮小）」與「重置視角」按鈕。
- **展開與收合**：節點下方帶有圓形按鈕（`+` 或 `-`），點擊可展開或收合該先人的所有後代子孫分支。
- **節點資訊卡**：展示世代世數、字輩、姓名、性別色彩指示條、配偶姓名、生卒干支時辰與生死狀態。
- **點擊成員節點**：
  - 點擊「檔案詳情」可在右側滑出抽屜檢視先人生平事略與生卒安葬細節。
  - 點擊「牌位排版」可直接攜帶該成員資訊前往牌位工作室進行排版。

### 4. 祖先牌位工作室 (Tablet Studio)
點擊頂部導航 **「牌位工作室」**：
1. **載入先人資料**：
   - 可自下拉選單選取族人，或直接手動編輯三行文字。
   - 點擊「依禮制重新生成標準三行牌位格式」自動產出範本。
2. **「兩生合一老」神主字數檢核**：
   - 系統依據純字數進行計算：
     - 中行字數必須合「老」（如 12、17、22 字）或「生」（如 11、16、21 字）。
     - 若字數落在「病」、「死」、「苦」，下方將顯示警示卡，並列出增減字建議按鈕（如：加「主」字、加「位主」以合老）。
   - 提供常用字快速插入工具條（`+公`、`+諱`、`+府君`、`+之神主`、`+之神位`、`+諡`、`+孺人`）。
3. **牌位外觀風格切換**：
   - **傳統紅木金字**：模擬木雕神主牌金漆雕刻質感。
   - **沉香黑檀金字**：高雅莊嚴的黑檀色調。
   - **白底列印紙樣**：黑白素雅外框，適合列印貼附於內牌木片。
4. **儲存與列印**：
   - 點擊「儲存此神主牌位」可將排版紀錄存入資料庫，隨時可在下方清單中載入。
   - 點擊右上角「列印排版紙樣」呼叫瀏覽器列印對話框。

### 5. AI 智慧問答助手與 FAQ 知識庫 (AI Assistant)
點擊頂部導航 **「AI 智慧助手」**：
1. **內建民俗禮制知識庫**：
   - 點擊左側分類 FAQ 清單（如「什麼是兩生合一老？」、「男考神主怎麼寫？」、「十二時辰對照表」），AI 助手將即刻提供引經據典之白話詳解與排版示範。
2. **宗族實體資料庫智慧感知問答**：
   - 可直接詢問：「我們開基祖是誰？」、「目前家族登錄了幾代、多少人？」、「陳廷玉的生卒年代為何？」等，AI 助手將即時搜尋本地 SQLite 資料庫並給出結構化摘要。
3. **後續問題智慧推薦**：
   - 每次回答後，助手會自動附帶相關問題推薦標籤，點擊即可無縫追問。
4. **外部 LLM 介接 (管理員可選)**：
   - 點擊左下方「配置 API」，管理員可填入 OpenAI 或相容介面（如 DeepSeek、Ollama 等）之 API Key 與自訂 Model，賦予助手更豐富的對話能力。

---

### 6. 會員註冊、登入與管理員權限控制 (Authentication & RBAC)
點擊頂部右上角 **「登入 / 註冊」**：
1. **預設測試帳號**：
   - **系統管理員**：帳號 \`admin\` / 密碼 \`admin123\`
   - **一般宗親會員**：帳號 \`clan_member\` / 密碼 \`user123\`
   - *(彈窗內提供一鍵快速填入按鈕，方便測試驗證)*
2. **一般使用者註冊**：
   - 點選「會員註冊」頁籤，輸入自訂帳號、族人稱呼與密碼即可立即完成註冊並自動登入。
3. **管理員專屬權限控制台**：
   - 以管理員身分登入後，進入 **「宗族與設定」** 頁面。
   - 上方即會顯示「宗親會員帳號與權限管理」清單，管理員可：
     - 將一般會員升級為「系統管理員」，或將管理員降級為「一般會員」。
     - 啟用或停用（停權）特定會員帳號。
     - 刪除違規或重複註冊之帳號。

---

### 7. 宗族設定與備份還原 (Settings & Backup)
點擊頂部導航 **「宗族與設定」**：
- **宗族基本設定**：可修改宗族名稱、總堂號、開基祖與世代輩序詩。
- **單鍵下載全庫 JSON 備份檔**：匯出完整的宗族設定、全體成員、親屬關係鏈與牌位設定。
- **從 JSON 備份檔還原**：上傳備份檔即可一鍵還原資料庫。
- **重置示範資料**：可隨時重置回內建之「穎川陳氏四代世系種子資料」。

## 傳統牌位格式民俗小辭典

| 神數 | 字數範例（餘數） | 吉凶 | 意涵與民俗原則 |
| :--- | :--- | :--- | :--- |
| **生** | 1, 6, 11, 16, 21, 26 字 | **吉** | 生生不息，子孫昌盛（神主與左右行皆適用） |
| **老** | 2, 7, 12, 17, 22, 27 字 | **吉** | 長壽富貴，德高望重（神主中行最為推薦） |
| **病** | 3, 8, 13, 18, 23, 28 字 | **凶** | 多病衰微，諸事不吉，應調增減字 |
| **死** | 4, 9, 14, 19, 24, 29 字 | **凶** | 終結斷絕，切忌使用 |
| **苦** | 5, 10, 15, 20, 25, 30 字 | **凶** | 奔波勞碌，清苦艱難，切忌使用 |

- **男考標準格式**：`顯考 [姓] 公 諱 [名] 府君 之神位`（常合 12 字或 17 字）
- **女妣標準格式**：`顯妣 [夫姓] 門 [本姓] 氏 諡 [諡號] 孺人 之神位`（常合 12 字或 17 字）
